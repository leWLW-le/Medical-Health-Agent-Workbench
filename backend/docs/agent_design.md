# Agent 架构与上下文

工作台有四个入口。FastAPI 的 LangGraph 主图负责分派、恢复对话和流式输出。账号模式由 Spring Boot 网关保存会话与报告，并代理 Python 服务。

| 入口 | 主图职责 |
| --- | --- |
| 健康对话 | `advisor_node` 提供健康科普、生活方式和就医准备信息，可使用本地知识检索和计算技能。 |
| AI 诊室 | `clinic_node` 子图先筛查危险信号，再收集症状。信息不足时通过 `interrupt()` 等待回复，随后给出分诊建议。 |
| 药管家 | `pharmacy_node` 解读药品信息，可调用药品、相互作用、用药计算和药店展示工具。上传药盒或追溯码会先经过视觉识别。 |
| 报告内容解析 | 照片或文字输入可进入 `report_node`。账号报告使用结构化字段、原页证据和报告解读节点，在同一报告修订下补问和恢复。 |

## 状态与工具

- `MainAgentState` 保存对话消息、活跃角色、下一节点、用户上下文和本轮转接次数。普通聊天通过 `thread_id` 使用内存或 SQLite 检查点。账号报告将字段修订与独立的报告检查点关联。
- 专科节点按标签加载 Pydantic 技能，并使用 `load_skill` 调度其他已注册技能。健康顾问和预问诊在生成前检索。报告照片对话可按来源筛选检验参考，药品工具按需检索。
- 可转接的专科通过 `Command` 把当前提问转给目标节点。每轮最多生效一次。结构化报告则由主图根据运行上下文直接进入证据检查。
- 节点、工具和结果通过 SSE 暴露执行进度。前端根据类型渲染文本、结果卡片和追问状态。
